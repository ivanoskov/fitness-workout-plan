# Vital Animations

Selected application media from the user-supplied VitalAnimations Free50 pack.
Source: https://vitalanimations.com/free-pack

MP4 files are web-optimized H.264 versions. JPG posters are the first decoded
frame of the corresponding source animation, resized to 480 × 480.
Exercise IDs retain the source numbering. This folder contains only assets
used by the workout page, not the full dataset.

These media are provided by Vital Animations and are not covered by a project
code license. Consult the provider's terms before reusing them independently.
